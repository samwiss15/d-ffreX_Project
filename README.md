**d-ffreX** is a free GUI application designed for crystallographers, microscopists, materials scientists, and students interested in indexing electron diffraction patterns (EDPs) or fast Fourier transforms (FFTs) and comparing the results with reference data from X-ray diffraction (XRD) databases.

The program considers only the kinematical approximation of electron scattering.

A user manual is currently available in Spanish, and an English version is under development.
